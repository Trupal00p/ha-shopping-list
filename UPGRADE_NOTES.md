# Upgrade Notes

## Current SDK Version: Expo SDK 58

- Expo: ~58.0 (all Expo packages are versioned 58.x)
- React Native: 0.88 (New Architecture only)
- React: 19.3
- Expo Router: 58.x
- Node.js: 22.13+ (see `.nvmrc`)

### Upgrade History

**October 2026:** Upgraded from SDK 51 to SDK 58
- Ran `npx expo install expo@^58.0.0 --fix`, then `npx expo-doctor@latest` (20/20 checks pass)
- Removed packages that were unused or only needed for SDK 51 workarounds: Redux Toolkit, react-redux, immer, react-art, `@expo/webpack-config` (and `webpack.config.js`; web uses Metro), and the Babel loose-mode private-methods plugins
- Replaced `react-native-vector-icons` with `@react-native-vector-icons/material-design-icons` (picked up automatically by React Native Paper 5.15; config plugin added for iOS fonts)
- Moved the top-level `splash` config into the `expo-splash-screen` plugin (the field was removed from the app config schema)
- `android/` and `ios/` are now gitignored and regenerated by prebuild. A native folder left over from an older SDK makes EAS skip `app.json` native config, so delete it after upgrading
- Code changes:
  - **Edge-to-edge is mandatory on Android.** Bottom UI pads by the safe-area inset, and `components/KeyboardAvoidingScreen.tsx` keeps the add-item input above the keyboard because the window no longer resizes for it
  - **Expo's fetch is the global `fetch` (SDK 56+)** and rejects with `FetchError` instead of `TypeError`. `lib/todoChanges.ts` normalizes fetch rejections so offline retries still recognize network failures
  - React Native 0.88's strict TypeScript API: refs use instance types such as `ViewInstance`
- R8 minification is on by default for release builds (SDK 58)

**November 2024:** Upgraded from SDK 49 to SDK 51 (React Native 0.72 → 0.74, expo-router 2 → 3)

### Future Upgrades

```bash
nvm use
npx expo install expo@^<next>.0.0 --fix
npx expo-doctor@latest
npx tsc --noEmit
rm -rf android ios   # regenerate native projects
task apk             # or: eas build --platform android --local --profile preview
```

Read each SDK's changelog at https://expo.dev/changelog for breaking changes.
